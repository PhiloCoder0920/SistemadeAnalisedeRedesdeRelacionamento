Estruturação e Leitura de Dados

Importação de arquivos e validação da integridade do grafo

Importação de Arquivos

Formatos suportados: JSON ou CSV

Clique ou arraste um arquivo JSON/CSV para enviar

Formato JSON esperado:

{
  "profiles": [{"name": "Ana"}, {"name": "Bruno"}],
  "connections": [
    {"from": "Ana", "to": "Bruno", "afinidade": 0.9, "interacoes": 150}
  ]
}

Formato CSV (conexões; os perfis são deduzidos):

from,to,afinidade,interacoes
Ana,Bruno,0.9,150
Bruno,Carla,0.7,80

Perfis podem ter x e y opcionais; sem eles, o grafo é distribuído em círculo. O campo weight também é aceito como afinidade.

Checklist de Validação do Grafo

Status da leitura, estruturação e validação

  • Leitura do arquivo
  • Estruturação de perfis (nós)
  • Estruturação de conexões (arestas)
  • Validação: sem nós órfãos
  • Validação: sem nomes duplicados
  • Carga do grafo na aplicação
